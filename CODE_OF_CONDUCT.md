# Contributor Covenant Code of Conduct

## Our pledge

We want participation in Dream Hosting Server Monitor to be respectful and welcoming to people with different backgrounds and experience levels.

## Expected behavior

- Be considerate, constructive and patient.
- Critique ideas and code without attacking people.
- Respect privacy. Do not publish another person's credentials, host data or private communication.
- Accept responsibility for mistakes and correct their impact.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate disruption, doxxing, and publishing private information without consent are not acceptable.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may restrict participation when necessary. Report concerns privately to the repository maintainer listed on GitHub. Maintainers should respond promptly and fairly.
